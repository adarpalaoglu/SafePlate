The notebook 05b_test_group_integration.ipynb had issues with cell execution
and has been replaced by a more robust Python test script.

Use instead:
    python tests/test_group_integration.py

This script tests the same functionality (group integration) but in a more
maintainable and debuggable form.

The notebook is kept for reference but should not be run.

---

Root cause: The notebook was written against the Phase 2 naive API
(TriggerDetectionResult, propagate_trigger_evidence, IndividualTrigger,
GroupTrigger), which was entirely replaced in Phase 3 by the DerSimonian &
Laird empirical Bayes shrinkage model. The import at cell 3 fails with:

    ImportError: cannot import name 'TriggerDetectionResult'
        from 'safeplate.group_aware_trigger_detector'

Cells 19-26 also use the removed API (propagate_trigger_evidence, etc.),
making this more than a minimal fix. The Python script covers the stable
parts of the API: group lookups and group-aware recommendation filtering.

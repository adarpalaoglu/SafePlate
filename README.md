# SafePlate

Third year CS project: SafePlate -- dietary trigger detection and meal recommendation system.

## Setup

### 1. Create a virtual environment and install dependencies

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
```

### 2. Prepare data

Place `RAW_recipes.csv` in `data/raw/`, then run the data pipeline:

```bash
python backend/scripts/prepare_data.py
```

This runs two steps (each is skipped if its outputs already exist):

1. **Data cleaning** -- cleans raw recipes, builds ingredient vocabulary and groups.
2. **Embedding training** -- builds co-occurrence graph and trains Node2Vec embeddings.

Use `--force-all` to regenerate everything, or `--force-cleaning` / `--force-embeddings`
to redo individual steps. Add `--verbose` for detailed progress output.

### 3. Run the Flask app

```bash
python backend/app.py
```

## Data Regeneration

To regenerate all processed data from scratch:

```bash
python backend/scripts/prepare_data.py --force-all --verbose
```

The notebooks in `notebooks/exploratory/` document the original research process
but are not required for production use.
